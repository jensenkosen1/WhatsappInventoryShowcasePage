What It Does

Everything your store needs,
delivered through chat

Each feature is triggered by a simple WhatsApp message. No app to install. No dashboard to log into.

WhatsApp as the Interface

The entire system is controlled via WhatsApp messages. Send a command, get an instant formatted report — no GUI required. Works on any phone.

Core Architecture

Real-Time Stock Tracking

Automatically calculates current inventory from initial stock, sales, migrations, and opname adjustments. Per-store and combined views.

Multi-Store Support

Manage multiple store locations independently. Each store (e.g., TL, MD) has its own inventory, sales records, and reports.

Excel Reports via Chat

Generates detailed mutation reports as .xlsx files in memory and sends them directly as WhatsApp attachments. No disk writes needed.

Accounts Receivable

Tracks credit sales (Piutang) and cash payments. Reconciles paid accounts and shows outstanding receivables at month-end.

Profit Analytics

Calculates total profit by comparing sales revenue against cost prices. Alerts when cost data is missing for any product.

Historical Snapshots

Query inventory as-of any past date. The system reconstructs stock levels using mutation history, so you can audit any point in time.

OCR Integration

Includes an OCR module to extract text from images sent via WhatsApp — enabling photo-based data entry for invoices and stock lists.

Workflow

How It Works

A simple pipeline from WhatsApp message to structured database report.

01
💬

Send a Command

Type a command in WhatsApp — e.g., laporan TL, stok as of 2025-11-01 TL, or mutasi dari 2025-10-01 MD.

02
⚙️

Bridge Processes

The WhatsApp Bridge receives the message, parses the command, and calls the Python inventory engine with the correct arguments.

03
🗄️

Database Query

Python queries the SQLite database — calculating current stock, sales totals, receivables, and profit from the stored mutations.

04
📤

Reply + Excel

A formatted text report is sent back to WhatsApp, along with an auto-generated Excel file (.xlsx) attached — all without touching disk.

Built With

Tech Stack

Carefully chosen for simplicity, reliability, and zero infrastructure cost.

🐍

Python 3

Core backend — inventory logic, report generation, WhatsApp command parsing.

🗃️

SQLite

Lightweight, file-based relational database. 7 tables: products, sales, migrate, opname, receivable, paid, costlist.

🐼

Pandas

Data manipulation, CSV ingestion, DataFrame sorting, and Excel file generation via openpyxl.

💬

WhatsApp Bridge

Custom bridge layer that connects WhatsApp messages to the Python backend as the user interface.

📊

OpenPyXL

Generates Excel mutation reports in-memory (BytesIO), then sends them as file attachments — no temp files needed.

👁️

OCR Engine

Extracts structured data from photos sent over WhatsApp — enabling image-based stock entry.

Data Model

Database Schema

Seven tables working together to give you a full picture of your inventory and finances.

📦 products / initial_products
id product_name price stock store / location

Master product catalog with initial stock levels per store.

💰 sales
id date customer_name product_name quantity price subtotal method (CASH/PIUTANG) store

Every sale transaction, with payment method tracking.

🔄 migrate
id product_name quantity date store

Stock movements between stores (BMBK transfers).

🔍 opname
id product_name price quantity date store

Physical stock count adjustments and corrections.

📋 receivable / paid
id date product_name subtotal status customer_name

Accounts receivable — outstanding and settled credit sales.

🏷️ costlist
id product_name price (buy price)

Cost prices used to calculate profit margins per product.
